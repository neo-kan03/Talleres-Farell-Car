# Talleres Farell Car · Demo de órdenes de reparación

Demo para el taller: tablero con los coches que hay en el taller y su estado, ficha de cada coche con lo que cuenta el cliente, el diagnóstico con fotos y las partidas propuestas.

- El presupuesto se envía al cliente por WhatsApp con el texto ya redactado.
- La respuesta del cliente (qué partidas acepta y cómo lo dijo) queda registrada con fecha y hora.
- Al terminar, se avisa al cliente por WhatsApp de que el coche está listo.

Es un único archivo HTML sin dependencias: abre `index.html` en el navegador. Todos los datos (clientes, coches, fotos e importes) son de ejemplo y no se guardan entre recargas.
